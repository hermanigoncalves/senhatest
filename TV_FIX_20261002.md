# Correção global das TVs — CMIPtst — 2026-10-02

## Problemas confirmados

1. O frontend público das TVs chamava `get_public_display_state`, mas a RPC não estava instalada no CMIPtst.
2. Quando a carga inicial falhava, `videoReady` permanecia falso e a tag `<video>` não recebia `src`, impedindo os vídeos institucionais de iniciar.
3. A tela pública de login não carregava os painéis ativos e, por isso, não exibia os atalhos para TV Recepção, TV1, TV2 e TV3.
4. O teste E2E vigente afirmava incorretamente que a tela de login não deveria enumerar TVs.

## Correções realizadas

- Adicionada `cmipApi.activeDisplayPanels()` usando `list_active_display_panels`.
- Restaurada a seção `Painéis de TV` no Login, carregada dinamicamente do banco.
- Cada TV ativa gera um link `/tv/<code>` sem login.
- Mantida a TV usando `get_public_display_state` para estado público sanitizado.
- Adicionada migration `20261002_restore_public_tv_state.sql`.
- Atualizados testes unitários/E2E para o requisito correto.
